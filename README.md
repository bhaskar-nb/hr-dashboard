## 📂 Dataset

This project uses a **synthetic HR dataset** created specifically for dashboard development and analytics practice.

### Dataset Generation

The dataset was generated using:

* Python
* Faker (Python Library)
* Pandas
* NumPy
* ChatGPT (for dataset planning and generation assistance)

### Dataset Summary

* **Total Records:** 8,950 Employees
* **Dataset Type:** Synthetic HR Dataset
* **Format:** CSV

### Dataset Fields

The dataset includes the following employee attributes:

* Employee ID
* First Name
* Last Name
* Gender
* Birth Date
* Hire Date
* Termination Date
* State
* City
* Department
* Job Title
* Education Level
* Salary
* Performance Rating
* Overtime Status

The dataset is completely synthetic and contains **no real employee or confidential organizational information**, making it suitable for educational, portfolio, and analytics projects.
